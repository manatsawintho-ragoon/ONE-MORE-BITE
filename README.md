# เอาอีก ONE MORE BITE

เว็บจัดการร้านอาหารสำหรับวิชา CSI402 โดย นายมนัสวิน ทองดี รหัสนักศึกษา 67091885

ลูกค้าสั่งอาหาร จองโต๊ะ แนบสลิป ดูใบเสร็จ และขอคืนเงินได้ พนักงานขายหน้าร้านและดูคิวครัว ผู้จัดการอนุมัติคืนเงินก่อนนักบัญชีบันทึกการคืนเงินจริง มีรายงานยอดขาย ใบกำกับภาษี และแจ้งเตือนงานตามหน้าที่

## เปิดใช้งาน

**สำหรับ Windows 10 หรือ Windows 11 แบบ 64 บิต Intel หรือ AMD**

1. [ดาวน์โหลดชุดพร้อมใช้](https://github.com/manatsawintho-ragoon/ONE-MORE-BITE/releases/download/v2026.11.21.1/ONE-MORE-BITE-Windows-x64.zip)
2. คลิกขวาไฟล์ ZIP แล้วเลือก Extract All เพื่อแตกไฟล์ก่อนเปิด
3. ดับเบิลคลิก **START.cmd** แล้วรอให้เว็บเปิด

มีโปรแกรมและฐานข้อมูลให้ครบ ไม่ต้องติดตั้ง .NET, SQL Server, Docker หรือ WSL เพิ่ม ชุดพร้อมใช้เปิดได้โดยไม่ต่ออินเทอร์เน็ตหลังดาวน์โหลดเสร็จ

เปิดหน้าต่าง START ค้างไว้ระหว่างใช้งาน เมื่อต้องการปิดระบบให้กลับมาที่หน้าต่างนี้แล้วกด Enter ข้อมูลยังอยู่เมื่อเปิดครั้งถัดไป

## ถ้าใช้ Git clone

```text
git clone https://github.com/manatsawintho-ragoon/ONE-MORE-BITE.git
```

เปิดโฟลเดอร์ ONE-MORE-BITE แล้วดับเบิลคลิก **START.cmd** ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดตัวโปรแกรม ครั้งต่อไปใช้ไฟล์เดิมได้ คนที่ไม่มี Git ให้ใช้ชุดพร้อมใช้ด้านบน

| หน้าที่ | อีเมล | รหัสผ่าน |
| --- | --- | --- |
| ลูกค้า | customer@customer.com | customer |
| พนักงาน | staff@staff.com | staff |

| นักบัญชี | accountant@accountant.com | accountant |

ลูกค้าเข้าสู่ระบบจากหน้าร้าน ส่วนพนักงานเลือกหน้าพนักงาน ฐานข้อมูลเริ่มต้นมีบัญชี อาหาร และโต๊ะให้พร้อมลองใช้งาน โดยไม่มีออเดอร์หรือข้อมูลลูกค้าจริง

## เก็บข้อมูลและย้ายเครื่อง

ข้อมูลที่ใช้งานจริงอยู่ในโฟลเดอร์ **data** รวมฐานข้อมูล รูปอัปโหลด และสลิป ให้ปิดระบบก่อนคัดลอกทั้งโฟลเดอร์เพื่อสำรองหรือย้ายเครื่อง เมื่ออัปเดตโปรแกรมให้เก็บโฟลเดอร์นี้ไว้

หากเว็บไม่เปิด ให้ดูข้อความในหน้าต่าง START และไฟล์ data/error.log โปรแกรมจะเลือกพอร์ตว่างให้อัตโนมัติ เปิด START เพียงหน้าต่างเดียวต่อโฟลเดอร์
